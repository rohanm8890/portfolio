# Rohan Marwaha — Personal Portfolio

A personal portfolio website featuring projects in electrical engineering, machine learning, embedded systems, and AI.

## Files

- `index.html` — main website
- `assets/incubator.jpg` — incubator project image
- `assets/link-adaptation-paper.pdf` — 5G NR link adaptation research paper

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload everything in this folder while preserving the `assets` folder.
3. Open the repository's **Settings**.
4. Select **Pages** in the sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Click **Save**.
8. Wait for GitHub Pages to finish deploying, then open the URL GitHub provides.

The root file must remain named `index.html`.
